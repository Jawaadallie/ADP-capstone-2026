# Shipment and Notification

This guide describes two backend entities in the Legendary Sprays E-Commerce Capstone.

## Shipment

The `Shipment` entity represents the delivery of a customer's order. Shipment information supports order tracking so customers can check the status of their delivery.

## Notification

The `Notification` entity represents a message for a user. It models the message as a record that the application can manage.
